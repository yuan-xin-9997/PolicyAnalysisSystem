# AI API 与 MCP 接入需求

## 机器身份

系统必须保留网页登录、CSRF 和用户页面权限，并提供独立、可过期、可撤销的随机凭据。凭据管理要求网页登录；机器凭据不能访问权限管理、凭据管理和配置接口。服务端只保存摘要。每次调用检查用户启用状态及实时权限与 scope 的交集。

验收：有效凭据可读取授权政策；匿名、空值、错误、过期、撤销凭据返回 401；缺 scope 或原页面权限返回 403；携带有效 Cookie 也不能挽救错误 Bearer。

## 版本化业务 API

复用 `/api/v1` 的政策、来源、类别、采集规则、采集任务、分析与比对任务服务。补齐 OpenAPI 认证、输入、响应、错误及调用示例。采集/分析为异步任务，创建响应包含 ID，后续可查状态、失败原因、日志及结果。原浏览器响应兼容。

Bearer 写请求必须带持久化幂等键；规则修改要求显式确认；同键同正文重放，同键不同正文或执行未完成返回 409。提供参数校验、原有分页、有界限流及统一错误。

验收：真实业务写入后查询到结果；并发及重试不新增重复操作；重启后保留幂等记录、完成结果、恢复排队任务，并给中断任务标记失败原因。

## MCP 服务

使用官方 Python MCP SDK 和 Streamable HTTP，提供 21 个具输入 schema、描述及准确属性的工具。工具只能通过相同受认证 API 调用业务，不直接修改业务表。所有 MCP 路径均受认证保护，非规范子路径不提供协议服务。

目标客户端为支持 `io.modelcontextprotocol/oauth-client-credentials` 扩展的官方 Python 客户端。实现资源元数据、授权服务器元数据、client_secret_basic/post、绑定 resource 的最长 15 分钟令牌。明确不将普通 API Key 当作通用远程 MCP 授权，也不声称支持未实现的交互式 OAuth/PKCE 客户端。

验收：真实 TCP 上使用官方客户端完成 OAuth 发现、initialize、tools/list、带 ISO 时间范围的查询、一次安全分析写入和幂等重试；工具业务失败必须 `isError:true`。无令牌访问规范或子路径均不能发现工具或读取数据。

## 网页凭据管理

现有设置区域必须提供 AI 接入子页，沿用登录、布局及 CSRF，所有已登录用户可管理本人凭据，系统配置页面的原权限不变。用户在页面填写名称、有效期和 scope，默认选择本人最小只读权限；服务端禁止伪造 scope、user_id 和跨用户撤销。分页列表只含元数据、当前有效范围及状态，不返回密钥。

完整密钥仅创建响应返回一次并禁止缓存；页面只在内存短暂保存，关闭须明确已保存，复制失败仍保留，离开前提示。退出、卸载和 pagehide 清除 DOM/内存，身份代次拒绝迟到响应。不得写入 local/sessionStorage、URL、日志、示例或下载文件。撤销须确认关联短期令牌立即失效，及时反映成功与失败状态。

页面必须展示当前 API/OpenAPI/MCP 地址、环境变量示例、已实测/仅协议适配/尚不支持的客户端、真实工具清单。短期令牌由客户端自动获取及续取；页面不提供默认写入测试。处理加载、空列表、错误、权限变化、过期、撤销及分页，适配桌面和 320px 移动端。

验收：使用真实 Chromium 在管理员和隔离普通用户下执行创建、复制、实际 API/MCP、重新打开无明文、确认撤销、旧密钥和关联令牌拒绝；伪造权限/管理他人请求被拒绝，原用户权限降低/停用立即影响已签发凭据；检查浏览器存储、URL、日志及产物无明文。

## 审计与部署补充

API/MCP 写操作记录身份、操作、目标、结果和时间；不记录原始凭据或敏感正文。OAuth 请求正文即使没有 Content-Length 也受大小限制。公开入口及兼容范围写入接入文档。

迁移只新增 AI 元数据表，提供 0008 回退 0007 及再升级验证；网页增量不改数据库。部署前完成依赖安装、测试和前端构建，检查活动任务并执行 SQLite 一致性备份及旧代码归档；保留整个 data、线上 app.json 和 service.env。停服期间只更新、切换预备运行环境、迁移和启动，明确秒级停服及旧环境/代码回滚方法。沿用现有网络范围。通过 Jenkins API 构建及生产 HTTPS 页面/API/MCP 语义验收后才标记已部署。
