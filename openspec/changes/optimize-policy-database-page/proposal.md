## Why

政策数据库当前要求用户手工输入发布部门、类别 ID 和来源 ID，检索含义与排序方向也不够直观，政策正文则以原始预格式文本展示，导致筛选、查找和阅读效率偏低。需要基于数据库现有数据和全文索引，提供更明确、可发现且易读的政策查询体验。

## What Changes

- 将发布部门、政策类别和政策来源筛选改为由数据库现有值驱动的可选项，避免用户记忆或猜测 ID。
- 区分标题关键词筛选与正文全文检索，新增独立全文检索框并保留可分享、可恢复的 URL 查询状态。
- 为“发布时间”和“最近抓取时间”提供明确的当前排序字段及升序/降序提示，并支持键盘和屏幕阅读器识别。
- 优化政策详情的信息层级、正文段落排版、长文本换行和阅读宽度，同时保持正文按纯文本安全渲染。
- 扩展政策查询 API 和筛选元数据 API，并补充后端、前端及端到端测试和相关项目文档。

## Capabilities

### New Capabilities

- `policy-database-experience`: 定义数据驱动筛选、标题与全文检索、明确排序状态以及可读的政策正文详情体验。

### Modified Capabilities

无。

## Impact

- 后端：`policy_analysis.policies` 的路由、查询模型、服务与仓储层；新增只读筛选元数据响应。
- 前端：政策列表、查询状态转换、政策详情、API 类型与全局/页面样式。
- 数据：继续使用 SQLite 与现有 FTS5 索引，不引入新数据库或外部搜索服务；预计无需迁移现有政策数据。
- 测试与文档：更新政策 API、服务、列表、详情及端到端测试，并同步 README、需求规格说明书和设计说明书中的相关页面与接口说明。
