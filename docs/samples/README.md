# 离线样本许可与来源

三份短文为本项目原创虚构演示文本，随项目按根目录 MIT LICENSE 授权使用、复制、修改和分发。并非政府文件，没有法律效力，不含第三方政策原文。

规范文本定义在 `src/app/backend/policy_analysis/demo.py` 的 SAMPLES；发布日期、发布机构均为虚构演示元数据，不应当作真实政策引用。localhost 原文地址是稳定去重标识，不提供真实网页；正文在政策详情中完整展示。

运行 `python -m policy_analysis.demo --data-dir <独立目录>` 导入；重跑按来源与固定URL跳过，不覆盖任何既有正文或账号。勿对生产目录运行。示例前两篇共同包含“教育”“资源”“教师”“培训”，第三篇为绿色出行，具体分词以引擎输出为准。

实际离线示例：选择前两篇正文后，报告输出 `pair_differences[0].similarity = 0.7526`（页面四舍五入为 75.3%），共同关键词包括“教育部门”“教师”“培训”；前者独有“图书”“开放”，后者独有“数字”“数据安全”。这是词频向量的相似程度，不表示政策效力或条款一致。依赖分词词典版本变化可能影响数值。
