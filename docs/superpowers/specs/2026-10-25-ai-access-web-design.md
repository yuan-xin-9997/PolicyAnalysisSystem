# AI 接入网页及发布设计

## 已有能力和范围

复用已部署的 `/api/v1`、21 个官方 SDK MCP 工具、OAuth client_credentials、机器凭据摘要、scope/用户实时权限交集、异步任务与幂等机制。新增网页管理入口和管理元数据，不另建后台、不开放删除业务或管理员代管他人密钥。

## 页面与权限

现有设置区域增加 `/settings/ai-access`，保留系统配置权限，所有已登录用户均可管理自己的凭据。复用 AppLayout、登录、CSRF、API client、北京时间格式和移动导航。无需新增 PageCode 或数据库迁移。

服务端 `/ai-access` 返回规范环境地址、本人可选 scope、真实工具清单和客户端兼容状态；`/ai-access/credentials` 返回本人分页元数据与当前有效 scope。旧 `/credentials` 管理接口保持兼容，前端不能传 user_id，服务端校验本人权限及管理员 scope。默认只选本人拥有的一项只读权限。

一次性密钥仅保留组件内存，不进入 URL/浏览器存储/日志/示例/下载文件。创建响应 no-store，对话框不自动刷新/关闭，关闭前明确确认已保存；路由离开提示，pagehide/卸载/退出清空 DOM 与内存。身份代次防止退出或 BFCache 离开后的迟到响应重新显示密钥。复制失败仍保留内容供手工保存。

列表展示标识、权限、北京时间、过期/撤销状态；确认撤销说明关联令牌立即失效。错误、无权限、空列表、分页、复制失败和撤销失败均有状态。默认不提供会写入业务的连接测试，页面示例仅查询/握手；客户端自动换取短期令牌。

## 审计与兼容

凭据成功操作沿用原审计；新增失败请求的身份、规范目标、状态审计。拒绝将任意撤销路径写入审计，避免误传密钥留存。列表不包含密钥，新接口仅添加元数据，不修改业务数据。

## 发布

Jenkins 在停服前完成测试、前端构建及隔离运行环境安装。新环境安装到 `.runtime-envs/<构建号>`，editable 源码保留在 `.runtime-releases/<构建号>`。停服前检查活动任务、备份 SQLite/配置/环境/密码及旧代码压缩包。停服后只 rsync（保护数据、配置及运行环境）、切换 `.venv`、迁移、启动，不再联网安装或构建。旧 `.venv-before-<构建号>` 保留回滚；预期秒级停服，不承诺无停机。

## 验证

组件测试覆盖创建/复制失败/清理/撤销/加载失败/迟到响应；后端测试覆盖伪造 scope/user_id、跨用户、CSRF、动态权限/停用、分页、审计脱敏。真实 Chromium 在管理员和隔离普通用户下执行网页创建、复制、API/MCP 调用、重新打开、撤销及 320px 导航/溢出检查，不保存 HAR/trace 或真实密钥。部署后使用实际 HTTPS 地址复测，并继续执行官方 Python MCP 客户端安全写入验收。
