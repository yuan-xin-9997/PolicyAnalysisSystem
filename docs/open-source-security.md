# 发布前人工安全操作

本轮仅静态检查，不验证、轮换或调用真实凭据。

发现已跟踪的 AGENTS.md 和 CLAUDE.md 各包含 WebFetch、翻译、OCR 三个服务的 API Key。本次将这些值替换为明显占位符。需由服务所有者轮换这三个凭据，检查历史暴露范围与访问日志；删除当前文本不能清除 Git 历史、克隆或缓存中的泄露。不要在未协调的情况下重写共享历史。

生产现有 password.txt 为兼容账号迁移而保留，不自动重置。首次新建文件使用随机口令；既有公开默认口令需由管理员主动更改。Windows 上应检查存放目录的 NTFS ACL，POSIX 的 0600 不等价于 Windows ACL。

本轮没有触发 Jenkins、部署、推送、发布或生产凭据轮换。GitHub Actions 需维护者在仓库启用后实际运行；私人 WebFetch/模型服务的连通性和授权尚未验收。
